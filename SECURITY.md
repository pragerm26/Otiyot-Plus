# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Otiyot+, please report it responsibly.

**Preferred method:** Open a private security advisory on GitHub (if available) or email the maintainer directly / open a confidential issue.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We will acknowledge receipt as quickly as possible and work with you to understand and address the issue. We ask that you do not publicly disclose the vulnerability until it has been resolved.

## Security Considerations for This Project

Otiyot+ is a browser extension that:
- Processes Hebrew text locally
- Stores only user preference settings
- Does not transmit personal or educational data by default

Because it runs with access to page content, any security issues (XSS vectors introduced by the extension, improper handling of untrusted PDF content, etc.) should be treated seriously.

Thank you for helping keep Otiyot+ and its users safe.
