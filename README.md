# Otiyot+

**Making Hebrew reading more accessible, one letter at a time.**

Otiyot+ is a Hebrew reading-accessibility browser extension designed to help English-speaking students, particularly Jewish students, learn to read Hebrew with greater confidence and independence.

Hebrew reading presents unique challenges for beginners, from unfamiliar letters and vowel markings to the visual complexity of traditional Jewish texts. For students with dyslexia and other reading difficulties, these challenges can make learning to read Hebrew especially demanding.

Otiyot+ helps address these barriers through customizable visual accessibility tools, including color-coded *niqqud*, a dyslexia-friendly font, adjustable letter spacing, and reading-focus mode.

**Our goal is simple: make Hebrew more readable and help every student engage more confidently with Jewish texts.**

## ✨ Features

Otiyot+ provides tools to make Hebrew text easier to read and navigate.

- **🎨 Niqqud Color-Coding** — Uses color to distinguish Hebrew vowel markings, helping readers identify vowels and recognize patterns more easily.
- **📖 Dyslexia-Friendly Font** — Offers a reading-friendly typeface designed to make letters easier to distinguish.
- **↔️ Adjustable Letter Spacing** — Increases the space between letters to reduce visual crowding and improve readability.
- **🎯 Reading-Focus Mode** — Helps readers concentrate on the text by reducing visual distractions.
- **↩️ Right-to-Left Support** — Accommodates Hebrew's natural reading direction.

The goal is not to change the Hebrew text itself, but to make its visual presentation more accessible to individual readers.

## 🎯 Who Is Otiyot+ For?

Otiyot+ is designed for anyone who wants a more accessible Hebrew reading experience, including:

- **Jewish day-school and yeshiva students** learning to read Hebrew.
- **Students learning Hebrew as a second language.**
- **Hebrew-school students** developing their reading skills.
- **Students with dyslexia or other reading difficulties.**
- **Teachers and educators** looking for ways to support diverse reading needs.
- **Anyone** who finds traditional Hebrew text difficult to read.

Whether you're learning to read a siddur, studying Tanach, or working through other Hebrew texts, Otiyot+ aims to make the experience more approachable.

## 🏫 Developed With Educator Feedback

Otiyot+ is being developed with input from educators and specialists who work with students with reading disabilities.

After discussions with specialists at [Shalshelet](https://shalsheletnj.org/), a school supporting Jewish students with learning disabilities, several opportunities for future development emerged.

Their feedback helped inform the project's direction, with a focus on practical tools that can support Hebrew reading both in the classroom and during independent study.

### Planned Improvements

The following features represent areas of planned development:

- **🎼 Trop and Cantillation Support** — Highlighting *ta'amei hamikra* (cantillation marks) to help students follow the structure and rhythm of Torah reading.
- **🔎 Shoresh Highlighting and Search** — Identifying and highlighting Hebrew root words (*shorashim*) to help readers recognize recurring word patterns and connections between words.
- **🖥️ Desktop Application** — Providing a dedicated environment for preparing and customizing Hebrew texts, including Tanach, Mishnah, Gemara, and siddurim.
- **📄 Accessible PDF Export** — Generating print-ready Hebrew reading materials with accessibility adjustments preserved.

These improvements aim to extend Otiyot+ beyond browser-based reading and make it a more comprehensive tool for accessible Hebrew education.

## 🚀 Installation

There are two ways to install Otiyot+: the stable version from the Chrome Web Store or the development version directly from GitHub.

### Option 1: Install the Stable Version (Recommended)

The stable version is recommended for most users who want a straightforward installation and a more thoroughly tested experience.

1. Visit the [Otiyot+ Chrome Web Store page](https://chromewebstore.google.com/detail/otiyot+/ejljnmjbnnpchiinedkomadkokfgiiec).
2. Click **Add to Chrome**.
3. Confirm the installation when prompted.
4. Once installed, click the puzzle-piece icon in Chrome's toolbar.
5. Find Otiyot+ and click the pin icon to keep it visible in your toolbar.
6. Click the Otiyot+ icon to access its accessibility features.

That's it! Otiyot+ is ready to use.

### Option 2: Install the Development Version (Less Stable)

**Want to try the latest changes?** You can install Otiyot+ directly from GitHub without using the Chrome Web Store.

The development version may include newer features, improvements, and bug fixes that have not yet been released in the stable version. However, it may also contain bugs or unfinished functionality.

This installation method is intended for users who want to test recent changes and are comfortable troubleshooting occasional issues.

#### Step 1: Download Otiyot+

1. Visit the [Otiyot+ GitHub repository](https://github.com/pragerm26/Otiyot-Plus).
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Once the download finishes, locate the ZIP file on your computer.
5. Extract the ZIP file into a folder.

**Important:** Remember where you extract the files. You will need to locate this folder during installation.

Alternatively, if you are familiar with Git, you can clone the repository and pull the latest changes whenever you want to update.

#### Step 2: Open Chrome's Extensions Page

1. Open Google Chrome on your computer.
2. Type the following into the address bar:

   `chrome://extensions`

3. Press **Enter**.

This opens Chrome's extension management page.

#### Step 3: Enable Developer Mode

1. Find the **Developer mode** toggle near the top-right corner of the page.
2. Turn it on.

You should now see additional options, including **Load unpacked**.

Developer mode allows you to install extensions directly from folders on your computer.

#### Step 4: Load Otiyot+

1. Click **Load unpacked**.
2. Navigate to the folder where you extracted the Otiyot+ files.
3. Select the folder containing the extension's `manifest.json` file.
4. Confirm your selection.

**Important:** Select the actual extension directory, not the outer download folder if `manifest.json` is nested inside another folder.

If Chrome reports that the manifest is missing or invalid, double-check that you selected the correct directory.

Once installation succeeds, Otiyot+ should appear on Chrome's Extensions page.

#### Step 5: Start Reading!

1. Open a webpage containing Hebrew text.
2. Click the puzzle-piece icon in Chrome's toolbar.
3. Find Otiyot+ in the extensions menu.
4. Optionally, click the pin icon to keep Otiyot+ visible in your toolbar.
5. Click Otiyot+ and enable the accessibility features you want to use.

You're all set!

#### Updating the Development Version

Unlike the Chrome Web Store version, the development version does not automatically receive updates from GitHub.

To get the latest changes:

1. Visit the [Otiyot+ GitHub repository](https://github.com/pragerm26/Otiyot-Plus).
2. Download the latest version using **Code → Download ZIP**.
3. Extract the updated files.
4. Open `chrome://extensions`.
5. If you extracted the new version into a different folder, click **Remove** on the old Otiyot+ installation, then click **Load unpacked** and select the new extension folder.
6. If you updated the files in the existing extension folder instead, click the **Reload** button on the Otiyot+ card.
7. Refresh any open Hebrew webpages to apply the changes.

**Tip:** If you use Git to manage the source code, you can pull the latest changes and reload the extension without repeatedly downloading ZIP files.

#### ⚠️ Important Notes About the Development Version

- **Less stable:** The development version may contain bugs, incomplete features, or unexpected behavior.
- **Manual updates:** You are responsible for downloading updates and reloading the extension.
- **Keep the folder:** Chrome loads an unpacked extension directly from its folder. Do not delete or move that folder while using the extension.
- **Trusted source:** Only install development versions from a source you trust.
- **Switching versions:** If you install both versions, Chrome may display two Otiyot+ entries. To avoid confusion, consider removing one version before installing the other.

For most users, the Chrome Web Store version is the better choice. The development version is intended for people who want to test recent changes and are comfortable with a less polished experience.

For additional guidance, see Google's [official Chrome extension development tutorial](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world/).

Once Otiyot+ is installed:

1. Open a webpage containing Hebrew text.
2. Click the Otiyot+ icon in Chrome's toolbar.
3. Enable the accessibility options that best suit your needs.
4. Adjust the reading experience as needed.
5. Continue reading with your preferred settings.

## 🔒 Privacy

Otiyot+ is designed with student privacy in mind.

Our privacy principles include:

- **No sale of personal information.** Otiyot+ does not sell users' personal information.
- **Local-first processing.** Hebrew text and reading activity are intended to remain on the user's device by default.
- **No collection of identifiable educational records.** Otiyot+ is not designed to collect student names, school records, or identifiable educational data.
- **User control over future AI features.** Any future optional AI-powered functionality should require explicit user action and be designed to minimize data sharing, particularly information that could identify a student.

These principles describe the project's intended privacy approach. Please consult the extension's current implementation and privacy documentation for details about the data it actually processes.
