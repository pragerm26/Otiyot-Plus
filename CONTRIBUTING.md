# Contributing to Otiyot+

Thank you for your interest in making Hebrew reading more accessible!

Otiyot+ welcomes contributions of all kinds: bug reports, accessibility suggestions, feature ideas, documentation improvements, and code.

## Ways to Help

- **Bug reports** – Something broken? Open an issue with steps to reproduce.
- **Accessibility feedback** – Especially valuable from teachers, parents, specialists, and students who use the tool.
- **Feature requests** – Ideas that help students learn to read Hebrew more confidently.
- **Code contributions** – Bug fixes, improvements to the PDF processor, better niqqud handling, etc.
- **Documentation** – Clearer instructions, translations, or examples.

## How to Submit Feedback or a Bug

1. Open an issue on the [GitHub repository](https://github.com/pragerm26/Otiyot-Plus).
2. Include:
   - What you were trying to do
   - What worked well
   - What didn’t work or was confusing
   - Any relevant accessibility concerns
   - Browser version and OS (if technical)

Feedback from educators and students learning to read Hebrew is especially helpful.

## Development Setup

1. Clone the repository.
2. Load the extension as an unpacked extension in Chrome (`chrome://extensions` → Developer mode → Load unpacked).
3. Make your changes.
4. Test thoroughly on Hebrew pages and with the PDF processor.
5. Open a pull request with a clear description of the change and why it helps users.

## Code Style & Guidelines

- Keep the code readable and well-commented, especially around Hebrew text processing and accessibility logic.
- Prefer local-first solutions.
- Accessibility and student privacy come first.
- Follow the existing project structure (`lib/`, `fonts/`, etc.).

## Pull Request Process

1. Fork the repo and create a feature branch.
2. Make your changes.
3. Test on real Hebrew content (siddur, Tanach, Gemara pages, PDFs).
4. Open a PR with a clear title and description.
5. Be ready for feedback and iteration.

Questions? Open an issue or start a discussion. We’re happy to help newcomers get started.

Thank you for contributing to making Hebrew more accessible!
